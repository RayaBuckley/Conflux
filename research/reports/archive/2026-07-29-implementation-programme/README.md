# Conflux implementation package

This package contains a concrete implementation plan and a work-in-progress fourth-year paper draft.

Files:

- `Conflux_Implementation_Technical_Specification.md`: primary Codex-facing specification.
- `Conflux_Codex_Implementation_Backlog.json`: machine-readable tasks with dependencies and acceptance criteria.
- `Conflux_Fourth_Year_Paper_Draft.md`: review-friendly manuscript.
- `manuscript/conflux_fourth_year_2026.tex`: standalone LaTeX draft.
- `manuscript/references.bib`: starter bibliography; entries explicitly marked for metadata verification must be reconciled with Zotero before submission.

Recommended repository placement:

```text
docs/specs/Conflux_Implementation_Technical_Specification.md
reports/Conflux_Codex_Implementation_Backlog.json
manuscript/conflux_fourth_year_2026.tex
manuscript/references.bib
manuscript/README.md
```

Leave the existing `paper/` directory unchanged as the archived previous-year paper.

The paper contains result placeholders by design. Do not replace them with the archived trace counts. Generate new tables from current result JSON files after the semantic and reproducibility milestones are complete.
