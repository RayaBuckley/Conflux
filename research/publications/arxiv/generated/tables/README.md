# Generated tables

Do not edit these files by hand. Each is written by

```sh
python scripts/generate_fourth_year_tables.py --outdir research/publications/arxiv/generated/tables
```

from the versioned result JSON under `research/output/runs/`. Every file header names its source
files and their SHA-256 digests. The tables here are the same generator output that the fourth-year
report ships, written to this directory so the arXiv paper is a self-contained submission tree.
