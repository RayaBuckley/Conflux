# Conflux reviewer-support package

This package contains **supporting/draft material**, not authoritative replacements for existing Conflux documentation.

Recommended workflow:
1. Copy the files into the repository at the paths represented here.
2. Ask GLM to inspect the current repository and reconcile these drafts with canonical documentation.
3. Do not overwrite `SECURITY_MODEL.md`, `SLED.md`, `STATUS.md`, `CLAIMS.md`, or architecture documents automatically.
4. Promote confirmed material into canonical documents through small reviewed changes.

The package focuses on:
- a fast research-reviewer entry point;
- concise research questions;
- a formal maximal-permissiveness / controller-synthesis proposal;
- a comparative-defence verification proposal;
- an experiment/result plan;
- a GLM synthesis brief.

These drafts are based on the supplied Part B report, preprint, prior repository analyses, and the research decisions discussed through August 2026.
